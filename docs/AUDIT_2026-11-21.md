# Fresh-eyes audit — 2026-11-21 (branch `feature/play-and-local-overhaul`)

Auditor: independent subagent, read-only. Audited against `docs/RESEARCH_STANDARD.md`
(proof over hope; measure first; one change at a time). Two builder workers were
active during the audit — in-flight areas are flagged as such, not scored as defects.

## Executive summary

The codebase is in materially good shape: the rules core is perft-proven and
clippy-clean, the v2 pipeline has real resume-reproduces-fresh proof, the server
API is properly validated and rate-limited, and the test suite (346) is green
with genuine assertions. But **one defect voids tonight's purpose**: the arena
"champion" is aliased to the live training model (`pipeline.py:479/508`), so
every in-run gate after the first plays the model against itself, can never
promote (score is pinned at 0.5 < 0.55), and burns a full 16-game arena per gate
for nothing. Second, FS-5 state saves serialize the **entire replay buffer**
(~2.6 GB per file at night-profile fill, never pruned) — a disk/RAM/stall hazard
that grows exactly while the run is unattended. Third, `train_log.jsonl` grows
without bound and the WS subscribe path re-reads the whole file per subscriber.
Ruff is red (149 errors, 129 in legacy modules) and CI has no Rust job. Fix
F-1 before launch; F-2/F-3 before or early in the night.

## Top 5 highest-leverage fixes

1. **F-1 — un-alias the champion (S).** Without it tonight's run cannot promote a
   single model past iteration 0 and burns ~half a training iteration's search
   budget per gate on model-vs-itself arenas. One-line-class fix + one test.
2. **F-2 — bound FS-5 state files (M).** ~2.6 GB/snapshot unpruned is the most
   likely way the overnight run dies by itself (disk or stall). Float16-npz +
   keep-newest-2 pruning.
3. **F-3 — journal rotation + bounded backlog reads (S).** Same failure family,
   same night: the site's train feed re-reads an ever-growing file per subscriber.
4. **F-4 — CI: add the Rust job, un-red ruff (S).** The perft-proven core is the
   only major component CI never checks; the lint job is already red on legacy debt.
5. **F-5 — fix candidate-Elo reset (S).** Cheapest honesty win: the ledger and
   Watch chart currently encode a rating history that never happened.
